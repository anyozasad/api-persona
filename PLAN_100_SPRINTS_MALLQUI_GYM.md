# Plan de 100 Sprints - Mallqui Gym

Objetivo: llevar Mallqui Gym a una versión completa, coherente y funcional, sin llenar el sistema de botones innecesarios. Cada sprint debe terminar con una función probada.

## Estado general

- Sprints 1 al 8: base funcional ya implementada en el proyecto.
- Sprints 9 al 100: plan de cierre, mejora, pruebas y estabilización.
- Un sprint solo se marca como terminado cuando la función se prueba en la interfaz, API y base de datos cuando corresponda.

## Criterio para llegar al 100%

Mallqui Gym se considerará terminado cuando los 100 sprints estén revisados, las funciones principales no tengan botones rotos o duplicados, administrador-cliente-entrenador compartan datos coherentes, Angular compile sin errores, Laravel pase sus pruebas y el sistema pueda ejecutarse correctamente en otra PC con su configuración documentada.
